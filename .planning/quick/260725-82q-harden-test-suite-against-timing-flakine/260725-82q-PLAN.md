Remove the wall-clock timing hazards from the test suite, unblock the one test seam that is broken by construction, put the suite behind CI, and write down the coverage picture that motivated the work.

Purpose: this is a baby monitor — the tests are the only thing standing between a refactor and a stream that silently dies overnight. Today nothing runs them on a PR, and several of them pass because a fixed `Future.delayed` happens to be long enough on an idle machine. Both make the suite untrustworthy in exactly the situation it exists for.

Output: a test CI workflow, a shared deadline-based `waitFor` helper replacing every hand-rolled poll loop and fixed sleep, an injectable background-validation delay, a working `setDioForTest` with tests that use it, a test-quiet AppLogger, and `docs/test-coverage-analysis.md`.

**files:** `test/support/async.dart`, `test/features/auth/auth_provider_test.dart`, `test/features/cameras/camera_provider_test.dart`, `lib/features/auth/providers/auth_provider.dart`

**verify:** `flutter test test/features/auth test/features/cameras` green, and the auth file's wall time drops by ~6s.

**done:** No `Future.delayed` remains in either file; every wait states what it is waiting for.

## Task 5 — Quiet the global AppLogger in tests

**files:** `lib/core/logging/app_logger.dart`, `test/support/logging.dart`

**action:** `AppLogger` is a process-global singleton that synchronously appends every line to the hard-coded `/tmp/rtsp_mixer.log` and holds a shared ring buffer plus a listener list. Under `flutter test` that is real disk I/O on every log call across all 315 tests, against one path shared by concurrently-running test processes. Add a `fileSinkEnabled` flag defaulting to `!Platform.environment.containsKey('FLUTTER_TEST')`, and a `resetForTest()` clearing buffer and listeners. Add `test/support/logging.dart` with `installAppLoggerTestIsolation()` for suites that render the log UI.

**verify:** Full suite green; `/tmp/rtsp_mixer.log` is not written during `flutter test`.

**done:** Tests no longer touch the shared log file, and the global buffer is resettable.

# Quick Task 260725-82q — Summary

Analysed test coverage, then removed the timing hazards from the suite and put
it behind CI.

| | Before | After |
|---|---|---|
| Tests | 315 | 336 |
| Line coverage | 46.3% (1455/3145) | 48.3% (1525/3158) |
| `protect_api_client.dart` | 7.2% | 93.2% |
| Wall-clock sleeping in tests | ~6s | 0 |

`flutter analyze --fatal-infos` clean. Full suite green.

## What changed

1. **`.github/workflows/tests.yml`** — nothing ran the suite on a PR before, so
   a red suite could reach `main` unnoticed. Runs analyze + tests with coverage
   on `pull_request` and pushes to `main`, uploads `lcov.info`. Still needs to
   be added as a required status check on the branch protection rule to block.

2. **`test/support/async.dart`** — `waitFor` / `waitForValue` /
   `waitForAsyncValue`, deadline-based with a `reason` quoted in the timeout.
   Replaces four hand-rolled `for (i < 100) { await Future.delayed(10ms) }`
   loops that expired silently (so a timeout surfaced as the *next* assertion
   failing, e.g. `Expected: 4 Actual: 1`, reading as a merge bug) and two
   fixed-sleep-then-assert races.

3. **`AuthNotifier.backgroundValidationDelay`** — injectable; tests collapse it
   instead of sleeping 3s twice for a 2s timer.

4. **`active_session_bar_test`** — uptime fixture moved from exactly 7m to
   7m30s, giving the `"Monitoring · 7m"` assertion ±30s of slack instead of 0
   against a widget that re-reads `DateTime.now()` every tick.

5. **`ProtectApiClient`** — `_dio` was `late final` and constructor-assigned, so
   `setDioForTest` threw `LateInitializationError` on every call. The client's
   only seam was dead by construction, which is why the `AppError` mapping that
   decides remote-host fallback vs credential revocation had no tests. Fixed,
   added `setHttpClientAdapterForTest` (keeps the real Dio's interceptors in the
   path) and an injectable `retryBaseDelay`, then covered error mapping, camera
   parsing, RTSPS alias extraction, and the 429 retry.

6. **`AppLogger`** — file sink off under `FLUTTER_TEST` (was a synchronous
   append per log line to one fixed path shared by concurrent test processes),
   plus `resetForTest()` / `installAppLoggerTestIsolation()` for the global ring
   buffer and listener list.

7. **`docs/test-coverage-analysis.md`** — measured coverage, ranked gaps with
   the reason each is hard, hazards fixed vs left open, suggested order.

8. **`per_camera_cancel_test`** — the new CI workflow failed on its first run and
   found a real pre-existing flake in a file this branch never touched. It
   asserted `['cam1', 'cam2']` against an attempt order decided by ±20% backoff
   jitter from an unseeded `Random`. Measured 3/24 failures (~12.5%) before,
   0/30 after seeding `Random(42)` and switching the precondition to
   `unorderedEquals`. The two other unseeded supervisor constructions were
   seeded prophylactically.

## Deviations

- Executed inline rather than via `gsd-planner`/`gsd-executor` subagents: this
  session's operating instructions prohibit spawning agents unless the user asks.
  All other GSD guarantees kept (plan artifact, atomic conventional commits,
  SUMMARY, STATE.md row).
- Added `ProtectApiClient.setHttpClientAdapterForTest` and `retryBaseDelay`
  beyond the planned `late final` fix — the plan called for testing the 429
  interceptor, and `setDioForTest` discards it along with the real Dio, so a
  transport-level seam was required.

## Left open (documented, not fixed)

- `camera_audio_card.dart` renders indeterminate progress indicators for the
  connecting/reconnecting states, so `pumpAndSettle` on those states spins to
  its 10-minute timeout. Currently dodged by folklore
  (`pump(50ms)` + a comment).
- `ActiveSessionBar` starts an unconditional `Timer.periodic(1s)` in `initState`
  even when it renders as `SizedBox.shrink()`; whether `pumpAndSettle` on a tree
  containing `MainShell` terminates depends on virtual-clock arithmetic.
- `StorageService` tests pass by relying on `FlutterSecureStorage` throwing
  without a binding, so they never exercise the secure path.
